# Air Pollution Data Analysis

## Project Overview
This project focuses on cleaning, analyzing, and understanding air pollution data using Python and Pandas.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- Data Analysis

## Project Objectives
- Clean and preprocess air pollution data
- Analyze pollution levels
- Identify patterns and trends in the data
- Perform data analysis using Pandas

## Files
- `air_pollution.ipynb` – Jupyter Notebook containing the complete analysis

## Key Skills Demonstrated
- Python Programming
- Pandas
- Data Cleaning
- Data Analysis
- Jupyter Notebook
